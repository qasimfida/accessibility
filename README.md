# Accessiblit

Accessiblit is a dependency-free accessibility personalisation widget for websites, with eighteen controls for text, colour and navigation. It supports plain JavaScript, TypeScript, React, Next.js, WordPress and other integrations. Personalisation does not make a website WCAG compliant. See the [installation guide](site/install/index.html) for integration examples and the [accessibility report](docs/ACCESSIBILITY.md) for tested scope and remaining manual checks.
