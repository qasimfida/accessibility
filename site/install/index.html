React

React is an optional peer dependency, version 17 or newer. An effect keeps DOM work on the client and cleans up the instance it created, including under StrictMode.

Next.js App Router

Create a client component and render it from your layout. The effect owns and cleans up the widget instance. React stays in your application rather than the core browser bundle.

Vue 3

Mount this component once in your application shell. Lifecycle hooks keep initialization in the browser and clean up the owned instance, including with server rendering.

Angular 17+

Render this standalone component once in the root template. afterNextRender runs only in the browser; DestroyRef releases the instance when Angular removes the component.

WordPress

This is a manual theme integration, not a WordPress plugin. Copy the IIFE to your child theme's assets folder and create accessibility-init.js using the plain JavaScript example above. Enqueue both from the child theme's functions.php; the dependency preserves initialization order.

Footer loading can show the original page before persisted preferences apply. For strict CSP, allow your local assets and pass the response's nonce to init. Do not paste credentials into theme files.

Shopify

This is a manual Online Store theme integration, not an App Store app. In a duplicate theme, upload accessiblit.min.js and accessibility-init.js to Assets. Use the initialization file shown above. Add these tags once in layout/theme.liquid before the closing body tag, preview and test before publishing the theme.

The theme serves these assets through Shopify's own asset infrastructure. The widget makes no requests after loading. Checkout and embedded third-party frames have separate platform restrictions. Footer initialization does not guarantee flash-free restoration.

Self-hosted file

Copy dist/accessiblit.min.js from your built package to your own static assets. This example assumes you serve it at /vendor/accessiblit.min.js. A strict CSP must also authorise your script and supply an owner nonce when fallback styles need one.
