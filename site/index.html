Make text easier to follow

Adjust font size, line height, letter and word spacing, alignment and readable fonts. Content scaling can enlarge the whole layout.

Choose a different colour palette

Use dark mode, high contrast, monochrome or lower saturation. Operating-system forced colours take priority.

Find your place on the page

Reading guides and masks follow the pointer, touch point or keyboard focus. Highlight links, headings and keyboard focus.

Keep settings between visits

Preferences are saved under one localStorage key. If storage is blocked, the current session still works. Persistence can be disabled.

Use the keyboard from the start

Open with Alt+A by default, move through native controls and close with Escape. The shortcut can be changed or disabled.

Keep the integration reversible

Reset restores default settings. Destroy removes the widget and its page adjustments. Imports are safe during server rendering.

Content

Font size

Scale text from 80% to 200%, in 10 percentage point steps.

Line height

Choose the original spacing, 1.5, 1.75 or 2.

Letter spacing

Choose original spacing, 0.12em, 0.16em or 0.2em.

Word spacing

Choose original spacing, 0.16em, 0.24em or 0.32em.

Text alignment

Align eligible text blocks left, centre or right without treating navigation and layout containers as text blocks.

Content scale

Zoom the page layout from 100% to 200%.

Readable font

Choose a system stack or an owner-preloaded dyslexia-friendly font, with a system fallback.

Colour and contrast

Dark mode

Use a dark HTML palette with light text.

High contrast

Use a strong text/background palette; this takes priority when dark mode is also enabled.

Monochrome

Remove colour from eligible page content.

Low saturation

Reduce colour intensity; monochrome takes priority when both are enabled.

Navigation and orientation

Reading guide

Follow a pointer, touch point or keyboard focus with a horizontal guide.

Reading mask

Keep a reading strip clear while gently dimming the surrounding page.

Highlight links

Outline and underline links, using more than colour alone.

Highlight headings

Outline headings and show a visual level badge.

Larger cursor

Choose 32px or 48px pointers on fine-pointer devices. Touch-only devices keep their native behaviour.

Stop animations

Pause CSS animation, remove transitions and smooth scrolling, and pause autoplay video.

Focus highlight

Emphasise keyboard focus with a two-tone ring.

Frequently asked questions

What does Accessibility actually do?

It adds a personalisation panel to your website. Visitors can adjust text, colour and navigation using 18 individual controls. It does not change your underlying content or repair inaccessible markup.

Is it really free for commercial websites?

Yes. The MIT license permits personal and commercial use. All 18 features are included. You provide hosting, integration and maintenance; managed hosting and guaranteed support are not part of the offering.

Will it make my website WCAG compliant?

No. A widget does not make a site conformant by itself. Accessible design, implementation, content and testing remain essential.

Does it send visitor data anywhere?

No. The widget has no tracking, cookies or runtime network requests. When enabled, persistence uses a single localStorage key in the visitor's browser.

Can visitors use it with a keyboard?

Yes. Alt+A opens the panel by default, native controls support keyboard input and Escape closes the panel. Site owners can change or disable the shortcut.

Can I choose which features appear?

Yes. Use the features allowlist or exclude option, and configure position, offset, messages and persistence through the public API.

What should I test on my own site?

Test your content, page layouts, fixed elements, forms and integrations with the settings you offer. Iframes, other shadow roots, canvas and rigid layouts have limitations.

Do font adjustments work with pixel-sized text?

Font scaling handles pixel-sized text as well as relative units. Rigid containers and third-party embedded content can still limit the result, so test your own pages at the largest settings.

Does Stop animations stop every kind of motion?

It stops CSS animations, transitions and smooth scrolling, and pauses autoplay video. Animated images, canvas and JavaScript-driven motion may continue.

What happens if browser storage is blocked?

The current session continues with an in-memory fallback. Settings cannot persist across visits when localStorage is unavailable.

Can I use it with React or Next.js?

Yes. Use the separate React component or hook, or initialise and destroy the toolkit in your own effect. The installation guide includes the Next.js client-component pattern.
